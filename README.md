在 iOS 设备上安装 AvPlay 需要使用“侧载”（Sideload）工具。<br>
两种安装方案：[Sideloadly](https://sideloadly.io) 和 [AltStore](https://altstore.io/#Downloads)

---

## macOS 无法打开解决方案

**方案 1**
1. 在终端中输入以下命令并回车：
```bash
sudo xattr -dr com.apple.quarantine /Applications/AvPlay.app
```

**方案 2**
1. 打开 `系统设置`
2. 左侧栏找到 `隐私与安全性` 项
3. 安全性设置点击 `仍要打开`
